# SAFER Verify — Prototype v0.1

A local-first research prototype for assessing an image's AI-generated signal and, optionally, inspecting C2PA Content Credentials.

**This is not a forensic verdict system.** It cannot prove an image is real or fake and must not be used alone to accuse people, remove content, or make high-stakes decisions.

## Features

- Upload PNG, JPG/JPEG, or WebP images (15 MB maximum).
- Run an ONNX image detector locally after downloading its model.
- Verify the downloaded model file against the SHA-256 published in the model card.
- Optionally inspect embedded C2PA manifests using `c2patool`, if installed.
- Display a file SHA-256 hash for identifying the exact uploaded bytes.
- Show explicit limitations and safer interpretation guidance.

## Model choice and caveats

Model repository: [TensorFold/detectra-v1](https://huggingface.co/TensorFold/detectra-v1)

The model card describes the model as Detectra v3, a ViT-S/16 binary classifier exported to ONNX. It describes the preprocessing as: resize shortest edge to 440, center-crop to 384, scale to [0,1], and ImageNet-normalize. It documents a 0.65 operating threshold and reports its own held-out results. Those results are **not independently reproduced or validated by SAFER AI**.

The model detects an AI-generated-image signal. It is not a universal detector for all deepfakes, face swaps, edited photos, or deceptive captions. Its score should not be described as a calibrated probability that an image is fake.

The repository lists an MIT license. Review the current model card and license before redistribution or deployment.

## Privacy

- Uploaded image bytes are processed by this local Streamlit process; the app does not send them to a remote inference API.
- On first run, the app downloads the model file from Hugging Face. The image itself is not uploaded to Hugging Face by the model-loading code.
- If `c2patool` is installed, the app invokes it locally on a temporary file and attempts to delete that file afterwards.
- This prototype has not undergone a security audit. Do not expose it to the public internet or upload highly sensitive material without additional review.

## Run locally

Requires Python 3.10 or newer.

### 1. Create an environment

```bash
python -m venv .venv
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 2. Install packages

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Launch

```bash
streamlit run app.py
```

On first use, the model is downloaded and cached locally. The initial download requires internet access.

## Optional: C2PA provenance inspection

Install the official [C2PA Tool](https://github.com/contentauth/c2patool) and make sure `c2patool` is available on your PATH. If it is absent, the app explicitly reports that provenance checking was unavailable.

The tool's output can include validation status. A manifest being present is not the same as a trusted signer or truthful content; inspect validation details and trust configuration.

## Research protocol — before claiming performance

This app is a prototype, not an evaluated research result. Before publication:

1. Pin the model repository to an immutable revision and record its SHA-256.
2. Select licensed datasets and record their provenance and terms.
3. Separate train/validation/test sources where applicable.
4. Define the evaluation protocol before running tests.
5. Compare against baselines and report precision, recall, false-positive rate, calibration, and coverage.
6. Test transformations and generators outside the training distribution.
7. Record model version, environment, hardware, and failures.
8. Never present the model card's published metrics as results obtained by SAFER AI.
